# Colony Game

A four-player couch economic strategy game for the browser, played with game controllers. Early development.

## Contents

- `index.html` — landing page
- `controller-test.html` — shows every connected controller and its button presses, to check how many controllers a browser supports

## Run locally

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
